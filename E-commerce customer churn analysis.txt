import os

# Check current working directory
print("Current Directory:", os.getcwd())

# List contents of parent and data directories
print("\nFiles in parent directory (..):", os.listdir('..'))
if os.path.exists('../data'):
    print("Files inside '../data':", os.listdir('../data'))
-------------------------------------------------------------------------------------
- os.getcwd() → Finds the folder where Python is currently working.
- os.listdir() → Lists files and folders.
- os.path.exists() → Checks whether a file or folder exists.
- os.mkdir() → Creates a new folder.
One small correction: OS is not limited to finding folder details. It can also create, rename and delete folders and work with files.

-'..' represents the parent directory (one level above the current working directory).
 {-'../data' mean?
It has two parts:
- .. → Go one folder backwards (parent directory).
- data → Look for a folder named data.}

import os

print("Everything inside '../data':")
for root, dirs, files in os.walk('../data'):
    print(f"Directory: {root}")
    print(f"  Folders: {dirs}")
    print(f"  Files: {files}\n")
----------------------------------------------------------------------------------
root  -	The name/path of the directory currently being visited.
dirs  -	List of folders inside that directory.
files -	List of files inside that directory.
